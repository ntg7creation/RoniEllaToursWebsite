# RoniElla Tours text archive

Captured 2026-09-23 from public HTML. `pages/` contains one Markdown file per successfully fetched URL; `raw_html/` preserves the corresponding original HTML; `pages.json` keeps ordered text blocks and internal links; `page_structure_and_order.md` maps the headings and form labels; `coverage.csv` lists successes and failures; `sitemap_sources.json` records discovery.

This is a snapshot of publicly accessible page HTML, not a WordPress database export. Dynamically loaded reviews, hidden form states, private pages, and text embedded in images or PDFs may be absent. Site header/footer text is removed from per-page extracts to avoid repetition but remains in raw HTML. Inspect coverage.csv before treating it as complete.
